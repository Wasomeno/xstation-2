# The Station Agent only Shows or Clarifies

Open-ended Commands are still requests to be taken somewhere. The agent does not answer from page copy, and it is not a general assistant. “What is Arkiv?” Shows Arkiv; the lede is already on the page. “How much?” Clarifies toward contact. A talking brochure is a later product.

The AI Voice Nav showcase requirements extend page actions to back/next navigation, contact CTA focus, and explicitly opening the existing WhatsApp link. Video demos are excluded. The agent still does not answer product questions or accept arbitrary URLs/selectors. See the current Page Action definition in `CONTEXT.md`.
