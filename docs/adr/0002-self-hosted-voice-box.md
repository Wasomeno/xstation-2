# Speech is transcribed by OpenAI; interpretation is DeepSeek behind the box

The live site is static GitHub Pages. After each Pause the browser sends a clip to an always-on box (this Mac + HTTPS tunnel now, Mac Mini later). The box calls **OpenAI transcription** (`gpt-4o-mini-transcribe`) then **DeepSeek** (`deepseek-chat`) to pick a Show or a Clarification. API keys stay on the box; they never ship in the Pages JS. Audio goes to OpenAI; the transcript goes to DeepSeek; the box does not keep audio. Local faster-whisper was replaced so Indonesian capture uses OpenAI’s voice model. The box allows only the site origins and rate-limits.
