# Local wake detection and persistent cloud conversation sessions

The VPS serves the static page and pinned sherpa-onnx WASM/model assets. After one microphone activation, the page detects “Hei Nadi” in a worker on the visitor's device. Idle room audio never reaches the voice box. The detector emits `nadi:wake`, then the browser opens a WebSocket to the box for a conversation session, also available by clicking the orb. The box proxies OpenAI Realtime transcription (`gpt-live-transcribe`); DeepSeek (`deepseek-v4-flash`) interprets the transcript. API keys stay on the box.

The existing microphone-energy detector commits after a 1.8-second speech pause. Only audio captured after a wake or click is buffered while connecting. Capture pauses during processing. A decision or no-action result resets the turn on the same socket and resumes listening; unmatched speech triggers the existing 500 ms fallback animation. Item IDs prevent stale results from affecting another turn.

OpenAI transcript delta/final events containing the whole word `thanks` or `terima kasih` (with or without the space, case-insensitive) close the cloud session and return to local listening. Clicking the orb toggles conversation/local wake listening. Escape releases all audio resources. Silence no longer ends the conversation after eight seconds; a 30-second commit bounds each upstream audio buffer, including silent turns. Connection and processing deadlines remain 10/30 seconds and fail back to local listening. Hidden pages close cloud capture and disable microphone tracks without manually suspending the audio graph; returning silently restores the previous conversation/local state, with an explicit resume control if needed. Local inference errors stop the microphone without cloud fallback.

The prototype targets foreground desktop Chrome over HTTPS (localhost for development). Shared-memory WASM requires COOP `same-origin` and COEP `credentialless`, supplied by the Nginx configuration and preview server. The model archive declares Apache License 2.0; provenance and dependency licenses ship alongside the assets. Indonesian-accent and booth-noise acceptance testing remains required before treating this experimental model as kiosk-ready.
