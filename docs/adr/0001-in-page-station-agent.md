# Page Actions run in the tab

The Station Agent is in-page code that Shows a Section (Lenis scroll + highlight) or activates a registered CTA. It is not a computer-use robot that clicks pixels. A generic browser-use agent would ignore the landmark list, fight Lenis, and is a different product. Hands stay in the tab; the always-on box returns a validated Show, CTA activation, Clarification, or no action. The only registered CTA is `bikinkonten-demo`: both pointer and voice activation use the same button to open a native demo dialog. The dialog keeps the voice control accessible, closes on Escape without ending the voice session, and closes before navigating to another section.
